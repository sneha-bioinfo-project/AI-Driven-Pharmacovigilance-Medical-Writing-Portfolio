# Literature Search Strategy & Methodology (PRISMA Framework)

## Overview

This document outlines the literature search and study selection strategy used to evaluate machine learning applications for adverse drug event (ADE) and adverse drug reaction (ADR) prediction using electronic health records (EHRs).

The workflow follows a PRISMA-based approach for identifying, screening, assessing eligibility, and selecting relevant studies.

---

## Database Search Strategy and Yield

The literature search was conducted across four primary databases:

| Database | Records Identified |
|---|---:|
| PubMed | 1,655 |
| Web of Science | 3,338 |
| Embase | 2,421 |
| IEEE Xplore | 66 |
| Additional sources | 0 |
| **Total records identified** | **7,480** |
