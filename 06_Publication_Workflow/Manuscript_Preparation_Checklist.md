# Manuscript Pre-Submission Quality Checklist

**Educational Portfolio Material – Quality Assurance Document**  
**Target Submission:** Peer-Reviewed Biomedical / Pharmacovigilance Journal  
**Language Standard:** UK English  

---

## 1. Structural & Technical Verification

- [ ] **Title Page & Metadata**
  - [ ] Title is concise, descriptive, and accurately reflects manuscript scope without overclaiming.
  - [ ] Running title provided (within journal character limits, typically < 50 characters).
  - [ ] Full author names, institutional affiliations, and ORCID iDs included.
  - [ ] Corresponding author contact details (email and institutional address) verified.

- [ ] **Abstract & Keywords**
  - [ ] Abstract word count conforms to target journal limit (e.g., ≤ 250 words).
  - [ ] Abstract structure matches journal guidelines (Structured vs. Unstructured).
  - [ ] Abstract accurately summarizes background, methods, key findings, and conclusions without containing references or unsupported claims.
  - [ ] 4–6 MeSH-compliant keywords selected and listed.

- [ ] **Main Text Structure**
  - [ ] Text follows required section hierarchy (Introduction, Methods, Results/Synthesis, Discussion, Conclusion).
  - [ ] Total word count (excluding references, tables, and legends) is within journal specifications.
  - [ ] UK English spelling and grammar verified consistently throughout (e.g., *optimise*, *pharmacovigilance*, *analysed*).

---

## 2. Scientific Integrity & Data Accuracy

- [ ] **Claim Verification**
  - [ ] Scientific statements cross-checked against source studies in the evidence matrix.
  - [ ] Terminology calibrated: No exaggerated language used (e.g., "structured search" used instead of "systematic review" where protocol was unregistered).
  - [ ] Methodological limitations explicitly stated in the Discussion section.

- [ ] **Reference Integrity**
  - [ ] In-text citation markers strictly match the reference list numbers.
  - [ ] Reference list formatted strictly to journal style (e.g., AMA or Vancouver format).
  - [ ] Bibliographic details cross-checked against PubMed records; pending fields flagged for pre-publication verification.
  - [ ] No fabricated, retracted, or ghost citations included.

---

## 3. Visual & Formatting Assets

- [ ] **Tables & Figures**
  - [ ] All tables created in editable text format (not embedded images).
  - [ ] Table headers, footnotes, and abbreviations clearly defined.
  - [ ] High-resolution figures supplied meeting journal DPI requirements (300 DPI for photos, 600–1200 DPI for line art).
  - [ ] Graphical abstract description / asset prepared per journal guidelines.

---

## 4. Ethical, Compliance & Administrative Declarations

- [ ] **Declarations & Disclosures**
  - [ ] Conflict of Interest (COI) statement included for all authors.
  - [ ] Funding/Sponsorship statement explicitly detailed.
  - [ ] Ethics committee approval or waiver statement included (if applicable; marked N/A for secondary literature review).
  - [ ] Author Contribution Statement included using CRediT taxonomy roles.

- [ ] **Pre-Flight Administrative Check**
  - [ ] Cover letter prepared and addressed to the designated Managing/Handling Editor.
  - [ ] License agreements and Open Access selections reviewed.
  - [ ] Manuscript file uploaded in target file format (.docx or .tex as required).
