# AI-Driven Pharmacovigilance: Evidence Synthesis & Publication Communication Portfolio

## Overview
This repository serves as an entry-level Medical Writing and Scientific Communication portfolio. It presents a literature-based review evaluating the integration of current machine learning (ML) methodologies into post-marketing surveillance, pharmacovigilance signal detection, and adverse event (AE) extraction from unstructured medical data.

The project demonstrates core competencies required for entry-level roles in **Medical Writing**, **Medical Communications**, **Pharmacovigilance**, **Clinical Research**, and **Medical Affairs**.

---

## Portfolio Objectives & Skills Demonstrated

### 1. Evidence Synthesis & Literature Analysis
* Executed a **structured literature search** using a documented PubMed strategy across biomedical databases to identify studies applying natural language processing (NLP) and machine learning to drug safety.
* Applied a **PRISMA-based study identification and screening workflow** to standardise document selection and data extraction into an evidence matrix.

### 2. Medical Writing & Technical Communication
* Authored a narrative review manuscript using formal **UK English**, adhering to scientific publishing standards for structure, clarity, and precision.
* Developed plain language communications and healthcare professional summaries translating technical AI and pharmacovigilance concepts for interdisciplinary stakeholders.
* Applied explicit **Medical Writing Standards** regarding terminology consistency and objective, non-overstated scientific reporting.

### 3. Publication Communication & Workflow Management
* Formulated a structured **Journal Selection Strategy** evaluating target journals based on scope, impact, audience reach, and author guidelines.
* Established a comprehensive **Manuscript Preparation Checklist** to enforce pre-submission quality control, data integrity, and reference verification.
* Drafted publication management materials, including a formal submission cover letter, reference tracking tables, and a peer-reviewer response template demonstrating point-by-point manuscript revision workflows.
