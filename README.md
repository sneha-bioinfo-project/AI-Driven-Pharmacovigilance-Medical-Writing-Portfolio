# AI-Driven Pharmacovigilance & Medical Writing Portfolio

## Overview

Welcome to my scientific and medical writing portfolio showcasing expertise in **pharmacovigilance, evidence synthesis, biomedical research communication, and literature-based scientific writing**.

This repository presents a structured portfolio developed from a narrative review manuscript exploring the application of **machine learning (ML) and electronic health record (EHR) analytics for early adverse drug reaction (ADR) detection**.

The portfolio demonstrates the workflow involved in transforming biomedical research into professional scientific communication deliverables suitable for **Scientific Writing, Medical Communications, Pharmacovigilance, Clinical Research, and Healthcare Analytics roles**.

# Research Focus

## Machine Learning for Early Detection of Adverse Drug Reactions Using Electronic Health Record Data

The central review topic explores how artificial intelligence and machine learning approaches can support proactive pharmacovigilance by analysing:

- Structured healthcare data

Key themes include:

- Machine learning algorithms for ADR prediction
- Data preprocessing and feature engineering
- Clinical dataset challenges
- Explainable AI (XAI)
- Federated learning approaches
